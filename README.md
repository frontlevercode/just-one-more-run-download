# Just One More Run

A precision platformer built on one move: a grappling rope. Swing, launch, chain anchors and keep your speed through a tutorial and 10 worlds, from a test lab at dawn to a summit under the aurora. Every level is timed, and your best run comes back as a gold ghost to race.

## Download

1. Go to [the latest release](https://github.com/frontlevercode/just-one-more-run-download/releases/latest).
2. Download `JustOneMoreRun-Setup-<version>.exe` and run it.
3. It installs in a few seconds, adds a desktop shortcut and starts the game.

The installer is not signed yet, so Windows may say "Windows protected your PC". Click **More info**, then **Run anyway**.

Needs Windows 10 or 11 (64-bit). A graphics card from the last few years is recommended; on a weaker one, lower Render resolution in Settings > Video.

## Controls

| Input | Action |
|---|---|
| A / D | Move, and pump your swing on the rope |
| W or Space | Jump |
| S | Fast fall |
| Hold left mouse | Fire the hook at the cursor, release to let go |
| W / S on the rope | Reel in / out |
| Space on the rope | Let go and jump (once per airtime) |
| R / Shift+R | Back to checkpoint / restart level |
| Esc | Pause |

Every key can be changed in Settings > Controls.
